# W24 — the home screen greets every entry point

Built on `main` at version 0.4.0. The version and tag were not changed. No runtime dependency was added.

## Delivered

- `@mstack/brand` now owns terminal mode selection and marked logo blocks through `renderTerminalLogo`. Normal non-TTY output is ASCII between `<<<MOB` and `MOB>>>`. TTY truecolor, 256-color and shaded mono remain unchanged. Explicit `--plain` and `--ascii` modes still override automatic selection.
- `mob`, `mob hello`, the `mob onboard` Ready screen and the skill splash all use that renderer. Headless full home screens stack the marked logo before the information rows.
- Every skill uses the shared splash. The first skill in an hour greets once per configured owner, or once per `MOB_HOME` when no owner exists. The router always greets. Directory locks suppress concurrent duplicate greetings.
- All 20 generated Claude and Codex `SKILL.md` files carry the exact verbatim-block rule. `/mob-setup` also requires the Ready home block at the top of its reply. The largest generated skill is 44 lines, below the 120-line limit.
- Every path in `docs/AGENT-INSTALL.md` runs bare `mob` after verification and requires the agent to reproduce its output. The canonical paste prompt remains five lines across the prompt doc, README and Mobius ask. The landing-page copy includes the marked ASCII logo.
- The paste-prompt and Journey E smokes now require the marked logo. The paste-prompt fixture accepts both a release tag and the pre-release `<tag>` placeholder when it redirects the install URL to its local server.
