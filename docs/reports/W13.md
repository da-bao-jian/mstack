## Built

  delivery rules, and release steps. `docs/PROCESS.md` holds the coordinator/implementer
  workflow and W0–W17 history index. No root `CLAUDE.md` exists.
- `scripts/gen-skill-docs.ts`, `skills-src/`, and host overlays: portable frontmatter,
  use-case-first descriptions, one-line preambles, direct references, and Codex `$mob-*`
  invocation forms. Both generated trees are committed: 18 skills, 18 references,
  and nine minimal `agents/openai.yaml` files. Version metadata comes from `package.json`.
- `bin/mob-preamble` executes the existing preamble relative to its physical location.
  Resolving the `bin` symlink before moving to its parent is required for clone installs.
  The router adds `--router` to the requested one-line command to retain W12's router-only
  hourly splash. Other skills use the bare command from the brief.
- The preamble reports `MOB_BIN`. A child shell cannot export `$MOB` or PATH to its caller,
  so skill bodies now use the printed path. The Codex locator checks `.agents` before
  the legacy `.codex` location. Existing health, config, and update failures stay explicit.
- `scripts/setup.ts`: primary Codex links under `~/.agents/skills`, compatibility links
  only when `~/.codex/skills` exists, safe uninstall from both, old-ledger migration,
  and modern-only auto detection. Existing conflicts and user replacements stay protected.
- `.claude-plugin/plugin.json`: display name, description, author URL, homepage, repository,
  license, and keywords; version preserved. Marketplace name and source already matched.
  `.mcp.json` keeps its plain plugin-root command. Removed the SessionStart install-notice
  hook and its script; the existing PreToolUse guard definition is unchanged.
- Added `SECURITY.md`, `CONTRIBUTING.md`, `CHANGELOG.md`, `THIRD_PARTY_NOTICES.md`,
  `docs/ARCHITECTURE.md`, `docs/USAGE.md`, issue/PR templates, `.editorconfig`,
  `CODEOWNERS`, and `renovate.json`. License copies come from the pinned installed packages.
- README now follows install → scan/setup/bind/open/manage → custody → agents → development.
  It is 153 lines, with 852 words outside code fences. The custody statement is unchanged.
- Tests cover portable frontmatter, names, descriptions, body and file bounds, reference
  existence, generated metadata, the shared instruction file, and installer migration.
  Prior static safety assertions remain; obsolete format and SessionStart assertions

## Qualifications and deliberate omissions

- The repository-root plugin is intentional. Local syntax validation is not directory
  approval. The lockfile and scripts that install packages remain review holds; `bin/`
  excludes claude.ai/Cowork. No directory submission or marketplace install into the
  user's real account was performed.
- The fresh loader page qualifies the brief's lockfile statement: automatic installs
  accept registry dependencies and skip workspace dependencies. The source-build shim
  remains necessary. README and architecture record this qualification.
- Fable supplied the SessionStart visibility finding. The current hooks page also
  mentions `systemMessage` for resumed-session cost reporting, so it does not fully
  corroborate a blanket “cannot show messages” claim. No interactive host experiment
  was performed. The unused install notice was removed as assigned.
- Direct AGENTS.md loading, skill grant lifetimes, implicit skill routing, and UI metadata
  rendering were checked against docs and file tests, not a new interactive model session.
  The local schema example defines the two OpenAI UI fields used; optional dependencies,
  icons, prompts, and policy overrides are omitted.
- Renovate's schema and documented Bun support were verified. The hosted bot and private
  vulnerability-reporting setting were not enabled or exercised. SECURITY provides a
  non-sensitive contact route if private reporting is unavailable.
- qrcode-terminal is Apache-2.0 with embedded MIT code, not plain MIT. The copied license
  retains its embedded notice. WalletConnect's existing Community License remains distinct
  from mstack's MIT license; no license replacement or dependency upgrade was made.
- W14's CLI sources, sign lifecycle, sign-guard implementation, and glossary files are
  untouched. W16's installer, release workflow/script, download shim, version bump, and
  future 0.3.0 changelog section are untouched. W16 should regenerate skills after its bump.
- No signing, funds movement, hosted MCP, server change, telemetry, or extra runtime
  dependency was added. This package does not self-assign the next work package.

### Upgrade-check diagnostic

The preamble captures Git fetch diagnostics, disables terminal credential prompts,
and prints one bounded reason instead of Git's raw stderr. Credential failures now say:

```text
UPGRADE_CHECK: fail (git fetch credentials unavailable or rejected)
```

DNS failures have a separate reason; other fetch failures name repository access
and network checks. Raw remote URLs and credential-helper output are not echoed.
The hourly stamp retains the reason, so a cached failure stays explicit without
another fetch or a stale `UPGRADE_AVAILABLE` result. Legacy two-field stamps still
work. Other update-check state/reference failures also have one diagnostic line.
The fixture regression emits Git's missing-username fatal error and a second helper
diagnostic, then checks empty stderr, exactly one failure line, and cached behavior.
