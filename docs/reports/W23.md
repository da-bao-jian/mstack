# W23 — distribution by a pasted prompt

## Delivered

- `docs/AGENT-INSTALL.md` is a 140-line, agent-only procedure. It detects the host without asking, gives one command path per host, verifies the CLI, and gives host-specific uninstall steps and install safety rules.
- `docs/AGENT-PROMPT.md` contains the five-line canonical prompt, the address-free and Codex variants, and ready-to-paste copy for `mob.exchange/agent`.
- `README.md` shows the canonical prompt below the logo and pitch. `docs/MOBIUS-ASKS.md` records ask G for the API-page and landing-page copy actions.
- `packages/agent-install.test.ts` extracts documented commands, checks their commands, flags, scripts, raw URL shape, line limit, and release-placeholder count.
- `scripts/smoke-paste-prompt.ts` extracts the Claude and Codex commands from the install guide. It uses disposable `HOME`, `CLAUDE_CONFIG_DIR`, and `MOB_HOME` directories, a local marketplace, and a local W16-style release server with the current compiled binary and SHA-256 sum.
- `scripts/release.ts` rewrites `<tag>` to `v<version>` in the install guide, prompt file, and README. It verifies no placeholder remains in those files. `--notes` reports the planned rewrites without editing files.
- `docs/READINESS.md` and `docs/BUILD-PLAN.md` carry the P2 skills-only hosted-MCP plugin and later Anthropic directory submission.
