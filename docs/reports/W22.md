# W22 — session onboarding, skills, and 0.4.0

## Delivered

- Changed `/mob-setup` into the page-first onboarding flow. It runs
  `mob onboard`, gives the checklist, accepts a pasted key through stdin without
  echoing it, and reruns onboarding through the Ready line.
- Changed `/mob-bind` into the repair and native ceremony path. It covers
  `mob bind --all`, `mob onboard --native`, and the explicit `c-N` rule.
- Updated open, manage, and close skills for `api-submit` Proposals, exact
  `mob submit p-N` handoff, manual and auto policy, and wallet-only edits.
- Added `/mob-keys` for safe import, show, list, revoke, and delete operations.
  Regenerated all 10 skills for Claude and Codex. Every `SKILL.md` is at most
  120 lines.
- Added safe read-only MCP tools `onboarding_status` and `key_status`.
  Proposal tools still stage only. MCP cannot import, submit, sign, change
  config, or reveal a key.
- Added paste-and-import guard fixtures. The hook permits stdin import. The CLI
  refuses a key on argv and does not print it.
- Added complete help entries and an exhaustive parser-table help test. Every
  command and subcommand must now return a `Usage:` first line and exit zero.
- Fixed the Ready screen contradiction and ceremony relative-expiry display.
- Added the Journey E smoke with fake auth, funding, and Strategy API services.
  It covers onboard → import → Ready → open → submit → status and scans the
  temporary home for key leakage.
- Updated onboarding, custody, architecture, usage, readiness, contributor,
  plugin, and release documents. Released workspace metadata as 0.4.0.

No runtime dependency was added.
