## Verified facts that drive this package
- Claude Code loads a repository's `AGENTS.md` at session start when no `CLAUDE.md` exists ("no CLAUDE.md found; AGENTS.md loaded"), expands `@path` imports inside it, and targets under 200 lines per instruction file. Codex reads the root `AGENTS.md` (32 KiB default limit) and nested `AGENTS.override.md`. A `CLAUDE.md` at a plugin root is not loaded as context and makes `claude plugin validate` warn. Therefore: ONE `AGENTS.md`, no root `CLAUDE.md`.
- Skills: `SKILL.md` under 500 lines; `name` must equal the directory name (lowercase, hyphens); `description` ≤ 1024 chars with the key use case first (Claude truncates the listing at 1,536 chars); supporting files in `references/`, `scripts/`, `assets/`, referenced one level deep; the Agent Skills spec allows only `name`, `description`, `license`, `compatibility`, `metadata`, `allowed-tools` (Claude-only fields such as `argument-hint` break uploads elsewhere). Claude substitutes `${CLAUDE_SKILL_DIR}`, `${CLAUDE_PLUGIN_ROOT}`, `${CLAUDE_PLUGIN_DATA}` in skill content, and `allowed-tools: Bash(${CLAUDE_SKILL_DIR}/scripts/x.sh *)` lets a bundled script run without a prompt. A skill's content stays in context for the rest of the session; an `allowed-tools` grant clears on the next user message.
- Codex discovers user skills in `~/.agents/skills` (repo-local `.agents/skills` first, then user, admin `/etc/codex/skills`), supports symlinked skill folders, optional `agents/openai.yaml` per skill, explicit invocation `$skill-name`, implicit by description. `~/.codex/skills` is not in the documented list.
- Plugins: a top-level `bin/` makes claude.ai and Cowork refuse the plugin (Claude Code loads it); a `bun.lock` at the plugin root makes Claude Code install those packages on plugin install and is a reviewer hold in the directory; `claude plugin validate --strict` must pass; publish via our own marketplace (`claude plugin marketplace add da-bao-jian/mstack`, `claude plugin install mstack@mstack`); the `<claude-code-hint>` CLI mechanism works only for Anthropic's official marketplaces (not ours); SessionStart hooks cannot show the user a message.
- Pre-submission (for a later directory listing): README ≥ 40 words at the plugin root, LICENSE present, non-image files ≤ 256 KiB, ≤ 512 files, no compiled binaries committed, MCP server commands as plain `${CLAUDE_PLUGIN_ROOT}/…` paths.
