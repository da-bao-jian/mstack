## W4.1 + W3.2 fixes — one commit `fix(skills,cli): preamble resilience, net APY ranking`

P1. Preamble: a failed `git fetch` makes the preamble `exit 1` after printing "Upgrade check failed". An offline user then cannot use any skill. A failed update check is a report, not a stop: print `UPGRADE_CHECK: fail` to stdout and continue with exit 0. Keep `MOB_MISSING` as the only stop. Also, the production API is slow to first byte: measured just now, `GET /api/client-ip` took 5.5 s and `/api/arbitrage/rates` 3.1 s, so the 5 s curl timeout produced `API_REACHABLE: fail` on a healthy server in my run. Use `GET $API_BASE/api/client-ip` (23-byte body) with `-m 10`. Update the preamble tests.

P2. `./setup --uninstall` leaves the empty `~/.claude/skills/mobstack/` directory it created. Remove directories that setup created and that are empty after unlinking; never remove a non-empty one.

P3. Ranking metric. With "qualifying+executable first, then raw spread", the default top 10 was seven Lighter-vs-Lighter-mainnet pairs at 0 fees and an 0.88%/yr ETH pair, above a 1704%/yr Bybit/Binance pair. Add to each `Opportunity`: `netApyPct = spreadAnnualizedPct − totalCostPct × (365 / holdDays)` with `totalCostPct = roundTripFeePct + builderFeePct + max(entryCostPct, 0)` — a negative mark-based entry cost is never counted as a gain (it is an estimate on marks, not executable depth), while `breakEvenHours` keeps the upstream signed semantics. `holdDays` is a `rankOpportunities` option, default 7, CLI `--hold-days`. When entry cost is unmeasured, `netApyPct` is `null` and sorts last. Then the default scan view becomes two sections, both sorted by `netApyPct` desc, thin rows hidden unless `--include-thin`: "Executable on Mobius" (top 5, `--top-exec`) and "Best anywhere" (top `--top`, default 10). `--executable` prints only the first section with `--top`; `--market` and `--all-pairs` apply to both. Add a `net APY` column; drop the `EXEC` column from the first section and keep it in the second. `--json` gets `view: { executable: [...], anywhere: [...] }`. Update tests, README, and the W3 report with the new default output on live data.
