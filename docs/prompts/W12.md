## 1. `packages/brand` (`@mstack/brand`)
`renderLogo({ size: 32|44|60, mode })` returns lines. Modes:
- `truecolor`: half-block rendering, two pixel rows per terminal row: top opaque + bottom opaque → `▀` with fg=top, bg=bottom; top only → `▀` fg=top; bottom only → `▄` fg=bottom; neither → space; reset after each cell; trailing spaces trimmed. 24-bit SGR (`38;2;r;g;b` / `48;2;…`).
- `ansi256`: same geometry, nearest xterm-256 color per palette entry (compute once).
- `mono`: one character per pixel row pair using shades: sky `░`, orange `▒`, navy `█` (pick the top pixel of the pair; if the top is transparent use the bottom). No escapes.
- `ascii`: same as mono with ASCII only: sky `-`, orange `+`, navy `#`.
`detectMode({ env, isTTY })`: `NO_COLOR` set or not a TTY → `mono`; `COLORTERM` of `truecolor`/`24bit` → `truecolor`; `TERM` containing `256color` → `ansi256`; otherwise `mono`; a locale without UTF-8 (`LC_ALL`/`LC_CTYPE`/`LANG`) → `ascii`. Export `palette`, the palette strip renderer, and a tiny `style()` helper (bold, dim, the four brand colors, reset) that is a no-op outside TTY/`NO_COLOR`.
