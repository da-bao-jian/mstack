## 1. `docs/AGENT-INSTALL.md` — written for an agent, not a person
Imperative, no choices, one path per host, every command copy-exact. Sections, in this order:
- **Detect the host** from the environment the agent already has: Claude Code (the `claude` CLI exists and the session has the Skill tool or `CLAUDE_PLUGIN_ROOT`-style variables), Codex (`codex` on PATH or `~/.agents/skills` exists), another MCP-capable client, or a plain shell. State the rule as a short decision list the agent can apply without asking.
- **Claude Code:** `claude plugin marketplace add da-bao-jian/mstack` then `claude plugin install mstack@mstack`; then install the binary so the plugin shim never needs Bun: `curl -fsSL https://raw.githubusercontent.com/da-bao-jian/mstack/<tag>/install.sh | sh` (the doc carries a literal `<tag>` placeholder that the release script rewrites to the real tag at release time, see section 4). Verify with `mob --version` (must print the tag's version) and `mob doctor`. Then the exact sentence to tell the user: restart Claude Code, then say "set me up".
- **Codex:** `git clone --branch <tag> https://github.com/da-bao-jian/mstack ~/.mstack && cd ~/.mstack && ./setup --host codex`, verify, then: start a new Codex session and say "set me up".
- **Other MCP clients (Cursor, Windsurf, Claude Desktop):** install the binary with `install.sh`, then add the server block `{"mstack": {"command": "<path-to-mob>", "args": ["mcp"]}}` to the client's MCP config (name the config file per client in a short table), verify `mob mcp` answers `tools/list`, and say that signing and key import stay in the terminal (`mob onboard`, `mob keys import`).
- **Plain shell:** `install.sh`, verify, `mob onboard`.
- **Verify** block shared by all hosts: `mob --version`, `mob doctor`, and what each line should say.
- **Uninstall** per host, including `claude plugin uninstall mstack@mstack`, `./setup --host codex --uninstall`, `rm -rf ~/.mob/bin`, and `mob keys delete` (local copy only; revoke on the page).
- **What the agent must never do** during install: no `sudo`, no edits to shell rc files beyond what `install.sh` prints, no key handling here (that is onboarding).
Under 150 lines. Every command in the doc is extracted by a test (`packages/agent-install.test.ts`) that checks: each `mob …`/`claude plugin …`/`./setup …`/`install.sh` command refers to a command, flag or script that exists in this tree; the raw URL pattern matches `https://raw.githubusercontent.com/da-bao-jian/mstack/<tag>/…` with a tag placeholder or a `v\d+\.\d+\.\d+` tag; and the `<tag>` placeholder count equals what the release script rewrites.
