# Brand assets

- `mob-logo.jpg` — the MoB logo (source, 400×400).
- `logo.json` — the logo as a palette-indexed pixel grid at 32, 44 and 60 px widths, generated by `logo-gen.py` (Pillow). Index 0 is transparent (the beige background), 1 sky `#7fd8ff`, 2 orange `#f66047`, 3 navy `#027bb0`. The CLI renders this grid at runtime with half-block characters (two pixel rows per terminal row), so a 44 px grid is 18 terminal rows.
- Regenerate: `python3 assets/logo-gen.py` from the repo root with Pillow installed. The output is deterministic.
